Component Gallery

Isolated components of the 1.0 design system. Every camera action goes to a simulated camera on this page (log at the bottom); nothing is sent to a real camera. Values come from the E-M1's own Wi-Fi value lists (camera/desclist.xml). Source of truth for look: Figma file "OMCAP Design System".

Iconography V4.0

Precision Scale

Swipe, drag or tap the scale; arrow keys work when it has focus. Snaps only to the listed camera stops. Fixed Range uses the same stops; with long lists (shutter: 61 stops) its ticks get dense, which is why Center Lock is preferred.

Precision Color Controls V9

Static reference in Figma; drag/snap, active axis and Color All still need interaction validation. Capability per E-M1 Mark I under each instrument.

View architecture

Full View: whole viewport, essential overlays. Clean View: overlays hidden, explicit way back. Panel View: live view beside the instruments, divider draggable (keyboard: focus the divider, left/right). Fit shows the whole frame; Fill crops the preview only. No view change produces a camera action (see log).
