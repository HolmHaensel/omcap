Adaptive Precision Scale V2.0

Every tick is one value from the camera's own list; long ticks with labels are main values (full stops, ISO doublings, whole EV, every 1000 K), short ticks real intermediate stops. AUTO, LOW, BULB and LIVE modes are semantic values set apart by a gap. Nothing is added at the ends. Swipe, drag, tap or arrow keys.

Precision Color Controls V9.1

One instrument in all three themes; only the paint changes. Astro Red identifies sectors by index, hue number or filter initial. Capability per E-M1 Mark I under each instrument.

Precision Detent Feedback

One detent engine for mouse, wheel/trackpad, keyboard, touch and crown: every valid value is one detent, no gliding, no coasting; one pulse per detent passed, none at the limits; a camera readback does not pulse again. Fast turning sends at most one command at a time; the newest wish replaces the waiting one.
