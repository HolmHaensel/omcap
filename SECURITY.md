# Security

E-M1 Capture runs only on your own computer, listens on `127.0.0.1` and refuses requests from
other web pages. It never writes camera firmware and changes the camera only when started with
`--allow-write`.

## Reporting a problem

If you find a way for another web page, program or network device to control the camera or
read files through E-M1 Capture, or anything that could damage a camera, please **do not open a
public issue**. Use GitHub's private vulnerability reporting instead:
**Security › Report a vulnerability** on this repository.

You will get an answer as soon as possible; this is a volunteer project.
